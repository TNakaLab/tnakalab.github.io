Sheets Core プライバシーポリシー / Privacy Policy

制定 / Effective: 2026-10-13

1. 対象 / Scope

Sheets Core は持ち主（TNakaLab）が自分のためだけに使う個人用の道具です。持ち主以外の利用者はいません。

Sheets Core is a personal tool used only by its owner (TNakaLab). There are no other users.

2. 扱うデータ / Data accessed

Google アカウントで持ち主が許可した範囲で、持ち主の Google スプレッドシートと Google ドライブのファイル（中身・コメント・共有の設定）を、持ち主の指示した操作のためだけに読み書きします。

With the owner's permission, the tool reads and writes the owner's Google Sheets and Google Drive files (content, comments and sharing settings) only to perform operations the owner instructs.

3. 保存と送り先 / Storage and transfer

道具は持ち主のパソコンで動き、Google の API とだけ通信します。認証の鍵は持ち主のパソコンにだけ保存します。データを販売したり、広告に使ったり、持ち主以外に渡したりしません。

The tool runs on the owner's computer and communicates only with Google APIs. Authorization tokens are stored only on the owner's computer. Data is never sold, used for advertising, or shared with anyone other than the owner.

持ち主は自分の仕事のために、AI アシスタント（例: Anthropic の Claude）を通してこの道具を動かすことがあります。その時、読み取った内容はそのアシスタントの中で処理されます。

The owner may operate this tool through an AI assistant used for the owner's own work (for example, Anthropic's Claude). In that case, data read by the tool is processed within that assistant.

4. 許可の取り消し / Revoking access

Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます: https://myaccount.google.com/connections

Access can be revoked at any time from the Google Account "Third-party apps & services" page: https://myaccount.google.com/connections
